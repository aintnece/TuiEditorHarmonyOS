# Phase 10.1 — 查找 / 替换 · CC/OpenCode 实施 spec

> 独立大批次。目标：在 Markdown 模式与 WYSIWYG 模式都能「查找 → 上/下一处 → 替换 / 全部替换」，替换操作**可撤销**（Markdown 模式走命令栈）。
> 本 spec 基于当前真实代码（已逐文件核对：EditorPage.ets / MdEditor.ets / Toolbar.ets / Editor.ts / EditorCore.ts / WwEditor.ets / editor.html / CommandManager.ts / MarkdownCommands.ts）。

---

## 0. 交互设计（最终形态）

编辑器顶部（Toolbar 之下、内容区之上）弹出一条 **查找替换条**（默认隐藏）：

```
[🔍 查找…            ] 3/7  [↑] [↓]   [替换为…            ] [替换] [全部替换]  [✕]
```

- 工具栏最右加一个「查找」图标按钮（`tui_find.svg`），点击开/关查找条。
- 查找框输入即时匹配（onChange 重算），右侧显示 `当前序号/总数`（无结果显示 `0/0`）。
- `↑`/`↓` 在匹配间循环跳转（到底回到第一个），同时高亮当前匹配。
- `替换` 只替换当前匹配，然后自动跳到下一个匹配。
- `全部替换` 一次性替换全部，结果数量用现有 `showToast` 提示（如「已替换 7 处」）。
- `✕` 关闭查找条并清除高亮。
- 大小写敏感：v1 固定**不区分大小写**（中文场景为主）；预留 `findCaseSensitive` 状态位但不做 UI 开关。

**已知限制（写进 status.md，不视为 bug）**：两模式都**只高亮当前匹配**，不做「全部匹配高亮」（Markdown 的 ArkUI TextArea 无法渲染多处高亮；WYSIWYG 不做 DOM 注入高亮，避免碰 ProseMirror 内部）。

## 2. `FindReplace.ts`（纯逻辑，ArkTS 严格模式）

```ts
/** 匹配区间（具名 class，禁止匿名对象字面量） */
export class Match {
  start: number = 0;
  end: number = 0;
}

export class FindReplace {
  /**
   * 扫描全部（不重叠）匹配。不用正则；逐字符比较，忽略大小写时用 toLowerCase 单字符比较。
   * 空 query 或 query 长于 text → 返回空数组。
   */
  static findAll(text: string, query: string, caseSensitive: boolean): Match[] {
    const out: Match[] = [];
    if (query.length === 0 || query.length > text.length) return out;
    const limit: number = text.length - query.length;
    let i: number = 0;
    while (i <= limit) {
      let ok: boolean = true;
      for (let j: number = 0; j < query.length; j++) {
        const a: string = text[i + j];
        const b: string = query[j];
        if (caseSensitive) {
          if (a !== b) { ok = false; break; }
        } else {
          if (a.toLowerCase() !== b.toLowerCase()) { ok = false; break; }
        }
      }
      if (ok) {
        const m: Match = new Match();
        m.start = i;
        m.end = i + query.length;
        out.push(m);
        i += query.length;      // 不重叠
      } else {
        i++;
      }
    }
    return out;
  }

  /** 全部替换（基于 findAll 的区间拼接，逐段拼，不用正则/不用 replace） */
  static replaceAll(text: string, query: string, replacement: string, caseSensitive: boolean): string {
    const ms: Match[] = FindReplace.findAll(text, query, caseSensitive);
    if (ms.length === 0) return text;
    let out: string = '';
    let cur: number = 0;
    for (let k: number = 0; k < ms.length; k++) {
      out += text.substring(cur, ms[k].start) + replacement;
      cur = ms[k].end;
    }
    out += text.substring(cur);
    return out;
  }

  /** 从 from 起（含 from）第一个匹配的下标；无则 -1 */
  static firstIndexAtOrAfter(ms: Match[], from: number): number {
    for (let k: number = 0; k < ms.length; k++) {
      if (ms[k].start >= from) return k;
    }
    return -1;
  }
}
```

> ArkTS：`text[i]` / `query[j]` 字符串下标访问合法（项目既有多处这么用）。禁 `Record`/`spread`/`any`/`\\` 正则。

## 3. `MarkdownCommands.ts` 增量

在文件尾部（`getBuiltinCommands()` 之前）新增两个命令：

```ts
/** 替换单处：args = [start, end, replacement]（start/end 为 md 字符偏移） */
export const ReplaceCommand: UndoableCommand = {
  name: 'Replace',
  execute(state: EditorState, ...args: string[]): EditorState {
    const md: string = state.markdown;
    const start: number = args.length > 0 ? parseInt(args[0]) : -1;
    const end: number = args.length > 1 ? parseInt(args[1]) : -1;
    const replacement: string = args.length > 2 ? args[2] : '';
    if (start < 0 || end < start || end > md.length) return state;

    const result: EditorState = state.snapshot();
    result.markdown = md.substring(0, start) + replacement + md.substring(end);
    const caret: number = start + replacement.length;
    result.selectionStart = caret;
    result.selectionEnd = caret;
    result.isDirty = true;
    return result;
  },
  undo(state: EditorState): EditorState { return state.snapshot(); }
};

/** 全部替换：args = [query, replacement, caseSensitiveFlag('1'|'0')] */
export const ReplaceAllCommand: UndoableCommand = {
  name: 'ReplaceAll',
  execute(state: EditorState, ...args: string[]): EditorState {
    const query: string = args.length > 0 ? args[0] : '';
    const replacement: string = args.length > 1 ? args[1] : '';
    const cs: boolean = args.length > 2 && args[2] === '1';
    if (query.length === 0) return state;

    const newText: string = FindReplace.replaceAll(state.markdown, query, replacement, cs);
    if (newText === state.markdown) return state;

    const result: EditorState = state.snapshot();
    result.markdown = newText;
    result.selectionStart = 0;
    result.selectionEnd = 0;
    result.isDirty = true;
    return result;
  },
  undo(state: EditorState): EditorState { return state.snapshot(); }
};
```

- 顶部 import 加 `import { FindReplace } from '../../find/FindReplace';`
- `getBuiltinCommands()` 里 push 这两个（`cmds.push(ReplaceCommand); cmds.push(ReplaceAllCommand);`）。

> 走 `CommandManager.execute` → 自动进撤销栈（快照），所以替换可撤销/重做。⚠️ **不要**在替换路径上用 `core.onContentChange()`（那个绕过命令栈）。

## 6. `editor.html` 增量（`window.__ww` 新增 3 个方法）

在 `window.__ww = { ... }` 对象里追加（**不要动已有的 setMarkdown/getMarkdown/setTheme/focus/exec**）：

```js
/** 选中 markdown 偏移 [start,end)（tui 按 markdown 偏移映射到 wysiwyg 位置）*/
selectRange: function (start, end) {
  try { ed.setSelection(start, end); ed.focus(); } catch (e) {}
},

/** 替换当前选区内容（先 setSelection 再 replaceSelection；change 事件会自然回传 nativeBridge）*/
replaceRange: function (start, end, text) {
  try {
    ed.setSelection(start, end);
    ed.replaceSelection(text);
  } catch (e) {}
},

/** 全部替换：markdown 级重写 + 显式回传（setMarkdown 在 programmaticSet 窗口内抑制 change）*/
replaceAllText: function (query, text, caseSensitive) {
  try {
    var md = ed.getMarkdown();
    var hay = caseSensitive ? md : md.toLowerCase();
    var needle = caseSensitive ? query : query.toLowerCase();
    if (!needle) return;
    var out = '';
    var i = 0;
    while (true) {
      var idx = hay.indexOf(needle, i);
      if (idx < 0) { out += md.substring(i); break; }
      out += md.substring(i, idx) + text;
      i = idx + needle.length;
    }
    if (out !== md) {
      ed.setMarkdown(out, false);
      if (window.nativeBridge && window.nativeBridge.onChange) {
        try { window.nativeBridge.onChange(ed.getMarkdown()); } catch (e) {}
      }
    }
  } catch (e) {}
}
```

依据（已 grep `toastui-editor-all.min.js` 确认均为公开方法）：
- `Editor.prototype.setSelection = function(e,t){ this.getCurrentModeEditor().setSelection(e,t) }`
- `Editor.prototype.replaceSelection = function(e,t,n){ this.getCurrentModeEditor().replaceSelection(e,t,n) }`
- `Editor.prototype.insertText`、`getSelectedText` 同理公开。

## 8. `EditorPage.ets` 接线

新增状态：
```ts
@State private showFindBar: boolean = false;
@State private findQuery: string = '';
@State private findReplacement: string = '';
@State private findMatchCount: number = 0;
@State private findMatchIndex: number = 0;   // 当前匹配在 matches 中的下标（0-based）；-1 = 无
private findMatches: Match[] = [];           // 非 @State（普通数组即可）
private mdCtrl: TextAreaController | null = null;   // 由 MdEditor.onControllerReady 回填
private wwEditor: WwEditor | null = null;   // 若拿不到组件引用，用 runScript 的替代方案见下
```

> ⚠️ **ArkTS：拿不到子组件实例**。WwEditor 需要暴露一个「父可调」的入口。方案：给 WwEditor 加 `onReady?: (run: (js:string)=>void) => void` 回调，在 `onPageEnd` 里把 `this.runScript` 的绑定传出去：
> ```ts
> // WwEditor.aboutToAppear / onPageEnd 中
> if (this.onReady) { this.onReady((js: string): void => { this.runScript(js); }); }
> ```
> EditorPage 里：`WwEditor({ ..., onReady: (run) => { this.wwRun = run; } })`，`private wwRun: ((js:string)=>void) | null = null;`
> （MdEditor 同理走 `onControllerReady` 拿 controller，直接 `controller.setTextSelection`。）

核心方法：

```ts
/** 重算匹配（查询变化 / 内容变化时调用） */
private recomputeMatches(): void {
  if (!editorContext.core) { this.findMatches = []; this.findMatchCount = 0; this.findMatchIndex = -1; return; }
  const md: string = editorContext.core.getMarkdown();
  this.findMatches = FindReplace.findAll(md, this.findQuery, false);
  this.findMatchCount = this.findMatches.length;
  if (this.findMatchCount === 0) { this.findMatchIndex = -1; return; }
  // 默认定位到光标之后第一个匹配（或保持当前）
  if (this.findMatchIndex < 0 || this.findMatchIndex >= this.findMatchCount) {
    const from: number = editorContext.core.state.selectionStart;
    let k: number = FindReplace.firstIndexAtOrAfter(this.findMatches, from);
    if (k < 0) k = 0;
    this.findMatchIndex = k;
  }
  this.highlightCurrentMatch();
}

/** 高亮当前匹配（两模式分发） */
private highlightCurrentMatch(): void {
  if (this.findMatchIndex < 0 || this.findMatchIndex >= this.findMatches.length) return;
  const m: Match = this.findMatches[this.findMatchIndex];
  if (this.editorType === EditorType.Wysiwyg) {
    if (this.wwRun) { this.wwRun('window.__ww && window.__ww.selectRange(' + m.start + ',' + m.end + ')'); }
  } else {
    if (this.mdCtrl) { try { this.mdCtrl.setTextSelection(m.start, m.end); } catch (_e) {} }
  }
}

private findNext(): void {
  if (this.findMatchCount === 0) return;
  this.findMatchIndex = (this.findMatchIndex + 1) % this.findMatchCount;
  this.highlightCurrentMatch();
}
private findPrev(): void {
  if (this.findMatchCount === 0) return;
  this.findMatchIndex = (this.findMatchIndex - 1 + this.findMatchCount) % this.findMatchCount;
  this.highlightCurrentMatch();
}

private doReplace(): void {
  if (!editorContext.core || this.findMatchIndex < 0 || this.findMatchIndex >= this.findMatches.length) return;
  const m: Match = this.findMatches[this.findMatchIndex];
  if (this.editorType === EditorType.Wysiwyg) {
    if (this.wwRun) { this.wwRun('window.__ww && window.__ww.replaceRange(' + m.start + ',' + m.end + ', decodeURIComponent("' + encodeURIComponent(this.findReplacement) + '"))'); }
  } else {
    if (editorContext.editor) {
      editorContext.editor.exec('Replace', String(m.start), String(m.end), this.findReplacement);
    }
  }
  // 内容变化后重算（change 监听里也会重算，这里主动跳下一个）
  this.recomputeMatches();
  this.findNext();
}

private doReplaceAll(): void {
  if (!editorContext.core || this.findQuery.length === 0) return;
  const n: number = this.findMatchCount;
  if (n === 0) return;
  if (this.editorType === EditorType.Wysiwyg) {
    if (this.wwRun) { this.wwRun('window.__ww && window.__ww.replaceAllText(decodeURIComponent("' + encodeURIComponent(this.findQuery) + '"), decodeURIComponent("' + encodeURIComponent(this.findReplacement) + '"), false)'); }
  } else {
    if (editorContext.editor) {
      editorContext.editor.exec('ReplaceAll', this.findQuery, this.findReplacement, '0');
    }
  }
  this.recomputeMatches();
  this.showToast('已替换 ' + n + ' 处');
}

private closeFindBar(): void {
  this.showFindBar = false;
  this.findQuery = '';
  this.findReplacement = '';
  this.findMatches = [];
  this.findMatchCount = 0;
  this.findMatchIndex = -1;
}
```

- 在已有 `editorContext.editor.on('change', ...)` 回调里追加重算：`if (this.showFindBar) { this.recomputeMatches(); }`（注意：**避免和 doReplace 里的主动重算形成双重跳转**——以 change 回调里的重算为唯一权威，`doReplace` 里去掉主动 `recomputeMatches()`，只在其后 `findNext()`；实现时择一，保证「替换后跳到下一个」且不跳两次。建议：change 回调负责重算并保持 index 不变，`doReplace` 在 exec 后 `this.findMatchIndex` 保持不变、由 change 重算后再 `findNext()`。**留实现者按此约束落地，但必须实测不跳两次**。）
- build() 里：Toolbar 调用处加 `onFind: () => { this.showFindBar = !this.showFindBar; }`；Toolbar 下方插：
```ts
if (this.showFindBar) {
  FindReplaceBar({
    themeColors: this.theme,
    query: this.findQuery,
    replacement: this.findReplacement,
    matchCount: this.findMatchCount,
    matchIndex: this.findMatchIndex + 1,
    onQueryChange: (q: string) => { this.findQuery = q; this.findMatchIndex = -1; this.recomputeMatches(); },
    onReplacementChange: (r: string) => { this.findReplacement = r; },
    onPrev: () => { this.findPrev(); },
    onNext: () => { this.findNext(); },
    onReplace: () => { this.doReplace(); },
    onReplaceAll: () => { this.doReplaceAll(); },
    onClose: () => { this.closeFindBar(); }
  })
}
```
- MdEditor 调用处加 `onControllerReady: (ctrl) => { this.mdCtrl = ctrl; }`（Split/Editor 两处都要加）。
- WwEditor 调用处加 `onReady: (run) => { this.wwRun = run; }`。

## 12. 验证清单（真机，DevEco）

Markdown 模式：
1. 打开含多次出现词的文档 → 点工具栏「查找」→ 输入词 → 计数显示 `1/N`，第 1 处被选中高亮。
2. `↓`/`↑` 循环跳转，计数同步，编辑器滚动到匹配。
3. 输入替换词 → 点「替换」→ 当前处被替换，自动跳下一处。
4. 点「全部替换」→ 全部替换，Toast 显示处数。
5. 撤销（工具栏/右键）→ 连续撤销能回退替换。

WYSIWYG 模式：
6. 切到所见即所得 → 重复 1–5 → 行为一致；替换后 Markdown 内容与预览同步（change 回传）。
7. 两模式间切换后查找条状态不炸（可正常关闭/重开）。

通用：
8. 无结果输入 → `0/0`，点击替换/全部替换无副作用。
9. 深浅色下查找条配色随主题（token 化）。
10. 关闭查找条后高亮清除。
